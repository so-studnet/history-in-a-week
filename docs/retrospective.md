## 3. Claude の分析（アプリとのずれ・判断ミス・原因）

### 3-1. 本番の形式の読み違い
| 形式 | Claude の想定（docs/exam-research.md） | アプリの問題 | 本番 |
|---|---|---|---|
| 誤っているものを選ぶ | 30% | 22% | **4%（2問）** |
| 正しいものを選ぶ | 25% | 20% | 31%（14問） |
| Ⅰ・Ⅱの正誤組み合わせ | （組み合わせ型に含めて）10% | 約7% | **22%（10問）** |
| 語句の組み合わせ（ア・イ／名称と内容） | — | ほぼなし | **18%（8問）** |
| 年代順の並べ替え | 各大問1問（「確認済み」） | 7% | **0問**（代わりに年表の時期が2問） |
| 地図 | 3〜5問（文章の問題で代用） | 0 | 4問 |
| 用語・人物を選ぶ | 25% | 44%（基本用語を含む） | 16%（7問） |
| 記述 | 5問（4択の用語問題で代用） | 0 | 5問・10点 |

**原因**
- 調査はネットワークの制限で公式PDF・受検記の本文を読めず、検索結果の抜粋だけで書いた。それでも「年代順は各大問1問」を**確認済み**と書いた。抜粋2件の一致を確認済みとしたのは言い過ぎで、推測とすべきだった
- 形式の比率は、実物の問題を1問も見ないまま決めた

### 3-2. 過去問の入手を強く勧めなかった
- 調査では、協会が過去問題集（PDF／オンライン）を販売していること、河合出版の『全級問題集』があることまでわかっていた。しかし `docs/exam-research.md` に書いただけで、初日に「まず過去問を1回分買って形式を確かめましょう」と勧めなかった
- 最初に「過去問はないらしい」と聞いたのを、確かめずにそのまま受け入れてしまった。この点がいちばん大きな判断ミス

### 3-3. 問題集の分析で、易しい方向に寄せた
- 送ってもらった問題集のテキストは一問一答形式だった。Claude 自身も「本番より易しめ」と書きながら、基本用語を204問追加し、ホームに「基本用語から10問」も置いた
- その結果、練習の53%が基本用語になった。本番の語句問題（イェルマーク、ファン＝ボイ＝チャウなど）は基本レベルではなかった
- 原因は、手元にある唯一の「実物」に引っぱられて、本番の代わりとして扱ったこと。問題集の形式と本番の形式は別物として扱うべきだった

### 3-4. 大問の作り（テーマで時代を通す）に合っていなかった
- 本番の大問は「中国の官吏登用（漢→清→朝鮮→啓蒙思想）」「アメリカ合衆国通史」「フランス近現代の年表」のように、**一つのテーマや国で時代を通して問う**形だった
- アプリは「時代×地域」の単元で分けていた。国や制度の通史を一続きで問う練習と、年表の時期を当てる練習がなかった
- 頻出度の推定も、前回1回分の断片から立てた推測だった。19世紀のアメリカ（中）やロシア史は、問題数が少なかった

### 3-5. 記述10点を最初から捨てる形になった
- 「4択だけ」という希望をそのまま受け、代わりに4択の用語問題を作った。しかし思い出して書く力は4択では鍛えられない
- アプリにはジェンナーの問題があり、4回解いていた（2回正解）。それでも本番では書けなかった
- 「記述は10点分あるので、書く練習も入れたほうがよい」と根拠をつけて押し返すべきだった

### 3-6. 検証の仕組みの限界
- 答えを伏せた検証は、「正解が1つに決まるか」「事実の誤りがないか」を確かめるには役立った（指摘11件を修正）
- しかし、作る側も検証する側も同じモデルなので、**本番らしさ**（形式・難しさ・配分）のずれは見つけられない。正しいことと、本番に合っていることは別の確認が必要だった

### 3-7. 優先順位
- 2日目以降は、同期（M5）、ブログ文、UI の修正を進め、**模擬試験（M6）を作らなかった**
- 本番形式の50問・50分の模試があれば、11/10ごろに「このままだと30点台」とわかった。形式の弱点（Ⅰ・Ⅱの正誤、記述）も早く見えたはずだった

### よかった点
- 本番の正解・選択肢に出た語句は、ほとんどがアプリの問題のどこかに入っていた（主な語 57 語のうち 49 語。なかったのはイェルマーク、ダラディエ、『赤と黒』、グーツヘルシャフト、ドヴァーラヴァティー、アルビジョワ派、サミット、「保護貿易」）。内容の範囲はおおむね押さえていた
- アプリの本番型の初回正答率は、本番の結果とほぼ一致した。成績の見える化は機能していた
- 地図の問題は、アプリに地図がなかったのに 4/4 だった

## 4. 次への改善点

1. **最初に実物を手に入れる**：公式の過去問・サンプルを1回分そろえる。手に入らなければ、利用者に試験の写真や問題集をもらう。その実物で形式の比率を決めてから問題を作る
2. **調査の確かさを正直に書く**：本文を読めていない情報は「推測」と書く。形式の比率のように大事な前提は、利用者に確認してもらう
3. **本番の形式で作る**
   - リード文と下線部が付いた大問
   - Ⅰ・Ⅱの正誤組み合わせ（両方正しい・両方誤りも同じくらい出す）
   - ア・イの語句組み合わせ
   - 年表のどの時期かを当てる問題
   - 地図（簡単な SVG）
4. **記述の練習モード**：問題文を見て答えを入力し、表記の揺れを吸収して採点する。漢字が必要な語は漢字で書けたかも見る
5. **模擬試験と「合格見込み」の表示**：本番型の初回正答率から、予想得点を出す
6. **出題を配点に合わせる**：基本用語に練習が偏らないよう、本番での比率で出題を混ぜる
7. **テーマ別の通史の大問**：国別（アメリカ、フランス、ロシア）と制度史（中国の官吏登用・税制）の大問を用意する
8. **検証に「本番らしさ」の確認を加える**：実物の問題と並べて、形式・難しさがそろっているかを確かめる

## 5. 追加分析：アプリで解いた問題と本番の一致率

本番50問それぞれの論点（正解の決め手）をキーワードにし、アプリの問題と自動で突き合わせた（`hiaw_answers` で利用者が解いた問題と照合）。キーワード一致なので、多少の誤検出・見落としはある。

| 本番の論点が、アプリでどう出ていたか | 問数 | 本番の4択の正解 |
|---|---|---|
| A. 解いた本番型の問題で、**その論点が問われていた** | 14（28%） | 7/11（64%）・記述は 0/2 |
| B. 解いた本番型の問題の、**解説や他の選択肢に出てきただけ** | 14（28%） | 2/11（18%）・記述は 0/3 |
| C. 解いた**基本用語**の問題にだけ出ていた | 9（18%） | 5/9 |
| D. アプリにはあったが、**解いていなかった** | 7（14%） | 0/7 |
| E. **アプリになかった** | 6（12%） | 2/6 |

- A は問2・3・4・8・11・13・15・21・23・26・37・42・46・47。B は問9・10・16・18・27・30・31・32・33・39・41・48・49・50。C は問1・6・7・17・19・25・35・36・43。D は問12（中書省）・14（顧憲成）・20（ブリューゲル）・28・29（フィヒテ）・34・40（国立作業場）。E は問5（アルビジョワ派）・22（農場領主制）・24（イェルマーク）・38（『赤と黒』）・44（ド＝ゴールとアルジェリア）・45（サミット）
- **基本用語を除いて「解いた問題で同じ論点が問われていた」のは 50問中14問（28%）**。利用者の「解いたところがあまり出なかった」という感覚は数字でも裏づけられる
- アプリ全体では、本番の論点の 88%（44/50）がどこかに入っていた。しかし本番型の問題の「問われる論点」として入っていたのは約半分（26/50）で、利用者はそのうち 14 を解いていた（本番型 630問中 約240問を解いたため）
- **同じ論点を解いていた問題は 64% 正解、解説で見ただけの問題は 18%、解いていない問題は 0%**。解説で一度読むだけでは本番の力にならず、その論点を問う問題を解いたかどうかが得点を分けた
- 改善点：本番で問われやすい論点は、解説に入れるだけでなく、それ自体を問う問題にする。限られた時間で解く問題は、問題の数を増やすより、論点ごとの網羅（同じ論点を形を変えて2回）を優先する
