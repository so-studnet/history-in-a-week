# 問題集テキストの置き場

利用者が Claude との会話にテキストを貼り、Claude が `sources/raw/` に保存する。

- **`sources/raw/` は Git に入れない**（`.gitignore` 済み）。このリポジトリは公開なので、書籍の原文は載せない
- Claude は原文を読んで、傾向の分析メモを `sources/analysis/` に書く（原文の転載はしない。頻出の語句・テーマ・形式・ひっかけ方の要約だけ）
- 問題を作るとき、作成役は分析メモを参考にする

## 貼り付けの形式

1回の送信ごとに、先頭に次の見出しを付けて会話に貼る。章の途中で区切ってかまわない。

```
### 送付 3 / 章: 第2章 中世ヨーロッパ / ページ: 40-52
（ここに本文をそのまま貼る。問題・選択肢・正解・解説をまとめてで構わない）
```

保存先は `sources/raw/送付番号.md`（例：`sources/raw/003.md`）。
